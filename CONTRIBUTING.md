# Contributing to WindoM

The full guide lives with the code: [`windom/CONTRIBUTING.md`](https://github.com/WindoM-app/windom/blob/main/CONTRIBUTING.md). For the site, see the [`website` README](https://github.com/WindoM-app/website#readme).

- Small fix (typo, minor bug): open a pull request directly.
- Anything bigger: open an issue first so we agree on the approach.
- Security problem: never a public issue, see [SECURITY.md](SECURITY.md).
