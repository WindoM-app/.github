# Security Policy

This policy applies to every repository in the WindoM-app organization unless a repository ships its own.

## Reporting a vulnerability

Please do not open a public issue.

- Preferred: use **Report a vulnerability** on the affected repository's *Security* tab (private vulnerability reporting).
- Or email **yehudabriskman@windom.app** with the subject `[WindoM Security]`.

Include what you found, steps to reproduce, the impact, and a suggested fix if you have one.

This is a small project: expect a first response within a few days. Confirmed issues are prioritized and fixed as soon as possible. Please allow reasonable time before disclosing publicly, and do not access or modify other users' data while testing.

## Scope

In scope: the WindoM Chrome extension, its backend API, authentication and token handling, OAuth flows, and the windom.app site.

Out of scope: vulnerabilities in third-party dependencies (report those upstream) and anything needing physical access to a user's machine.

## Personal data

If you believe personal data was exposed, say so in the report. Requests about your own data go to the same address; see the [Privacy Policy](https://windom.app/privacy).
