# Getting help

- **Using WindoM, setup, how-to:** https://windom.app/support
- **A bug:** open an issue on [windom](https://github.com/WindoM-app/windom/issues/new/choose)
- **A website problem:** open an issue on [website](https://github.com/WindoM-app/website/issues/new/choose)
- **A security problem:** see [SECURITY.md](SECURITY.md). Never in a public issue.
